# ULTIMATE-CUSTOM-FILE-GENERATOR
### what is it
UCFG is a custom file generator that lets you download your plain text file in any file format you want.
### how to use it
1. enter your file content in [data] input.
2. enter your file name in [file name] input.
3. enter your file format in [file format] input.
4. download by clicking on "download" button
